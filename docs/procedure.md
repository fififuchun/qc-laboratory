# 環境を作る

## コマンド

以下を順に実行する。

```bash
git init
uv init --bare --python 3.12
uv add qiskit qiskit-aer matplotlib pylatexenc
```

## 入れたツール

| ツール                     | 役割                        |
| -------------------------- | --------------------------- |
| `qiskit`                   | 量子回路を作る本体          |
| `qiskit-aer`               | 手元のMacで動くシミュレータ |
| `matplotlib`、`pylatexenc` | 回路図やグラフの描画用      |

| ---- | --------------- | ----- |

## 何が起きている？

> 2枚のコインを「必ず同じ面が出る」ように結びつけて投げる実験を、1000回繰り返している。

量子ビットは「回っているコイン」にたとえられる。回っている間は `0` とも `1` とも決まっておらず、この状態を**重ね合わせ**と呼ぶ。

### コードの流れ

1. **コインを2枚用意する**：`QuantumCircuit(2)`

   `q_0` と `q_1` がどちらも `0` で始まる。

2. **1枚目を回す**：`qc.h(0)`

   `q_0` が重ね合わせになる。

3. **2枚を結びつける**：`qc.cx(0, 1)`

   `q_0` が `1` なら `q_1` を反転する。そのため、「2枚とも `0`」と「2枚とも `1`」の可能性が同時に存在する。この状態を**もつれ**と呼ぶ。

4. **コインを止めて見る**：`qc.measure_all()`

   ここで結果が決まる。2枚はセットなので必ず揃う。

5. **1000回繰り返す**：`shots=1000`

   測定すると状態は終わるので、毎回最初からやり直す。

### 結果の見方

- **回数のばらつき**：1回ごとの結果はランダムなので、ちょうど500回ずつにはならない。518回と482回は普通の範囲。
- **シミュレータ**：`AerSimulator` はMacの中で動きを再現するソフトで、本物の量子コンピュータは使っていない。
- **`01` と `10` が出ない理由**：誤りが起きない設定だから。実機ではノイズのため少し出る。

### 注意

- **コインはあくまでたとえ**：本物のコインと違い、量子ビットは測定するまで結果が決まっていないと考えられている。
- **この結果だけでは、もつれの証明にはならない**：「同じ結果を2枚の紙に書く」ような古典的な仕組みでも、同じ結果を再現できるため。
